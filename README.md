# 车上点名

一个手机端本地离线点名工具。支持从 Excel 或在线表格粘贴导入名单，在手机上标记已到/未到，筛出未到人员并直接调用拨号。

## 使用方式

启动本地服务：

```bash
python3 -m http.server 8765
```

然后打开：

```text
http://127.0.0.1:8765
```

## 当前功能

- 上传 `.xlsx` / `.xls` / `.csv` 名单。
- 粘贴在线表格内容并解析。
- 手动确认姓名、手机号、身份证号列。
- 身份证号只显示后四位。
- 手机号完整显示。
- 标记已到、未到、未点。
- 按全部、未点、未到、已到筛选。
- 点击拨号直接打开手机拨号界面。
- 一键清空本轮点名标记，名单保留。
- 名单和点名状态保存在当前浏览器本地。
- PWA 离线缓存，首次加载后可在弱网或无网环境使用。

## 注意

第一版不包含 OCR。图片或截图名单建议先用手机系统自带文字识别复制成表格文本，再粘贴导入。
